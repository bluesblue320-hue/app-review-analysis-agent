## 10. 优先级规则

- P0：数据泄露、越权、删除失效、跨数据集串读；立即停止发布。
- P1：数据丢失、数据库不可用、确定性功能整体中断、迁移失败；Gate 阻断。
- P2：模型降级异常、性能超标、部分 UI 流程不可用；当前迭代修复。
- P3：非关键体验和优化；不影响 Gate，可排后续。

所有新增需求先判断是否影响 Gate A。与安全、正确性和持久化无关的扩展不能挤占 Gate A 阻断项。
